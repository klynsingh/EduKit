# EduKit – The Student's Convenience Store

This repository contains the source code for the official **EduKit** website.

EduKit provides students with essential services including **Xerox & printing, online form filling, scanning, lamination, spiral binding, and stationery products**.

## Live Website

🌐 [https://edukit.in/](https://edukit.in/)

## Built With

- HTML5
- CSS3
- JavaScript

## Deployment

The website is hosted on [Cloudflare Pages](https://pages.cloudflare.com/) and automatically deployed from this GitHub repository.
